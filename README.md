# ربات تشخیص الگوی دو قله / دو دره (داده از بایننس، فیلتر شده روی نمادهای توبیت)

این ربات قیمت رو از **بایننس** می‌گیره (سریع و پایدار)، ولی فقط روی ارزهایی کار می‌کنه که
فیوچرزشون توی **توبیت** هم لیست شده. تو تایم‌فریم ۵ دقیقه، هر **۳۰ دقیقه یک‌بار** چک می‌کنه و
وقتی الگوی «دو قله» یا «دو دره» با اختلاف خیلی کم بین دو نقطه در حال شکل‌گیری تشخیص بده،
بهت پیام تلگرام می‌فرسته.

## راه‌اندازی سریع با گیت‌هاب (پیشنهادی)

به‌جای دانلود دستی فایل‌ها، ساده‌تره یه ریپوی گیت‌هاب بسازی و مستقیم توی Termux `clone`اش کنی:

1. توی [github.com](https://github.com) وارد حساب خودت شو (یا یکی بساز، رایگانه).
2. یه ریپوی جدید بساز، مثلاً با اسم `dtop-bot`.
3. سه فایل `main.py`, `requirements.txt`, `README.md` رو با دکمه‌ی **Add file → Upload files**
   توی همون صفحه‌ی ریپو آپلود کن و Commit بزن.
4. توی Termux:
   ```
   pkg install git -y
   git clone https://github.com/USERNAME/dtop-bot.git
   cd dtop-bot
   ```
   (به‌جای `USERNAME` یوزرنیم خودت رو بذار)

هر وقت فایل‌ها رو توی گیت‌هاب عوض کردی، کافیه توی Termux بزنی `git pull` تا آخرین نسخه بیاد.

## نصب

روی کامپیوتر عادی (لینوکس/ویندوز/مک) کافیه:
```bash
pip install -r requirements.txt
```

**روی Termux (اندروید) این روش رو استفاده کن** — چون `ccxt` به‌صورت پیش‌فرض به `aiohttp` نیاز داره
که کامپایلش روی گوشی سخته و لازم نداریمش (این ربات از حالت sync استفاده می‌کنه):
```bash
pkg install python-numpy python-scipy python-cryptography -y
pip install python-telegram-bot==21.4
pip install ccxt --no-deps
pip install requests certifi setuptools
```
اگه بعد از این دستورات پیام‌های قرمزرنگ «dependency conflict» دیدی نگران نباش — این‌ها فقط
هشدارن، نه خطای واقعی؛ تا وقتی در پایان «Successfully installed …» رو دیدی، مشکلی نیست.

## گرفتن توکن ربات و Chat ID

1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده و با دستور `/newbot` یک ربات جدید بساز.
   یک توکن به این شکل بهت می‌ده: `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ`

2. برای گرفتن Chat ID خودت:
   - به ربات [@userinfobot](https://t.me/userinfobot) پیام بده، عددی که برمی‌گردونه Chat ID توئه.

## اجرا

```bash
export TELEGRAM_BOT_TOKEN="توکن ربات"
export TELEGRAM_CHAT_ID="چت آیدی خودت"
python main.py
```

ربات هر ۳۰ دقیقه به‌صورت خودکار روی چارت ۵ دقیقه‌ای اسکن می‌کنه (قابل تغییر با
`SCAN_INTERVAL_SECONDS` در `main.py`) و در صورت پیدا شدن الگو، پیام می‌فرسته. همچنین می‌تونی با
دستور `/scan` اسکن فوری بزنی.

## دستورات تلگرام

- `/start` — راهنما
- `/mode all` — پایش تمام نمادهای مشترک بین بایننس و توبیت (پیش‌فرض)
- `/mode custom` — پایش فقط نمادهایی که خودت اضافه می‌کنی
- `/add BTC/USDT` — اضافه کردن نماد (فقط در حالت custom)
- `/remove BTC/USDT` — حذف نماد (فقط در حالت custom)
- `/list` — نمایش حالت، تایم‌فریم، تلورانس و تعداد نمادهای تحت پایش
- `/settimeframe 5m` — تغییر تایم‌فریم (مثلاً 1m، 5m، 15m، 1h، ...)
- `/settolerance 0.3` — حداکثر درصد اختلاف مجاز بین دو قله/دره
- `/refresh` — به‌روزرسانی لیست نمادهای مشترک
- `/scan` — اجرای فوری اسکن روی کل لیست

## نحوه‌ی تشخیص الگو (منطق ساده‌شده)

1. برای هر نماد، آخرین ۱۵۰ کندل ۵ دقیقه‌ای از بایننس گرفته می‌شه (به‌صورت موازی، حداکثر ۸
   درخواست هم‌زمان برای رعایت محدودیت نرخ درخواست).
2. با استفاده از `scipy.signal.argrelextrema` قله‌های محلی (برای دو قله) و دره‌های محلی
   (برای دو دره) پیدا می‌شن.
3. اگر دو قله/دره‌ی آخر:
   - فاصله‌ی زمانی کافی از هم داشته باشن (حداقل ۴ کندل)،
   - اختلاف قیمتشون کمتر از مقدار تلورانس تنظیم‌شده باشه (پیش‌فرض ۰.۳٪، با `/settolerance` قابل تغییره)،
   - بین‌شون یک حرکت واقعی (حداقل ۰.۱۵٪) وجود داشته باشه (برای حذف نویز)،
   - و نقطه‌ی دوم به‌تازگی شکل گرفته باشه (در ۶ کندل اخیر)،

   آنگاه به‌عنوان «الگوی در حال شکل‌گیری» علامت‌گذاری می‌شه.
4. اگه قیمت فعلی از خط گردن رد شده باشه (پایین‌تر برای دو قله، بالاتر برای دو دره)، در پیام
   قید می‌شه «تایید شده»، وگرنه فقط «در حال شکل‌گیری» اعلام می‌شه.
5. برای جلوگیری از اسپم، هر الگوی مشخص فقط یک‌بار اعلام می‌شه؛ تا وقتی همون دو نقطه دوباره
   تشخیص داده بشه، پیام تکراری ارسال نمی‌شه.

## نکات مهم درباره‌ی حالت «همه‌ی نمادها»

- لیست نمادها (نمادهای مشترک بایننس/توبیت) هر یک ساعت یک‌بار به‌صورت خودکار کش می‌شه؛ برای
  به‌روزرسانی فوری از `/refresh` استفاده کن.
- با تلورانس خیلی کم (مثلاً ۰.۱٪ تا ۰.۳٪) ممکنه هشدارهای زیادی دریافت کنی چون نوسانات
  کوتاه‌مدت هم می‌تونن این شرط رو برآورده کنن؛ اگه لازم بود با `/settolerance` و تغییر
  `MIN_DIP_PCT`/`PEAK_ORDER` در کد، حساسیت رو تنظیم کن.

⚠️ این یک ابزار کمکیه و مثل هر تحلیل تکنیکال دیگه‌ای قطعی نیست؛ به‌عنوان تنها ملاک تصمیم
معاملاتی ازش استفاده نکن.

## اجرای دائمی (اختیاری)

برای اینکه ربات همیشه روشن بمونه، می‌تونی از `tmux` توی Termux استفاده کنی تا با بستن ترمینال
برنامه متوقف نشه:
```
pkg install tmux
tmux new -s bot
python main.py
# با Ctrl+B سپس D از session خارج شو (برنامه ادامه پیدا می‌کنه)
```
همچنین حتماً Termux رو از بهینه‌سازی باتری اندروید مستثنی کن تا سیستم‌عامل نکشتش.
